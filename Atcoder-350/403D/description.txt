You are given a sequence of N integers A_1, A_2, ..., A_N.
Find the number of ways to partition this sequence into one or more contiguous subsequences such that the sum of each subsequence is even.

**Input:**
The input is given from Standard Input in the following format:
N
A_1 A_2 ... A_N

**Output:**
Print the answer modulo 998244353.

**Constraints:**
- 1 <= N <= 2 * 10^5
- 1 <= A_i <= 10^9
- All input values are integers
