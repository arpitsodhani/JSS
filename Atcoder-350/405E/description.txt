You are given a sequence of N positive integers A_1, A_2, ..., A_N and an integer K.
Find the number of non-empty contiguous subsequences whose sum is at most K.

**Input:**
The input is given from Standard Input in the following format:
N K
A_1 A_2 ... A_N

**Output:**
Print the answer.

**Constraints:**
- 1 <= N <= 2 * 10^5
- 1 <= K <= 10^{15}
- 1 <= A_i <= 10^9
- All input values are integers
