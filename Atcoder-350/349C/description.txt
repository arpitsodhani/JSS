A string T of length 3 consisting of uppercase English letters is an airport code for a string S of lowercase English letters if and only if T can be derived from S by one of the following methods: Take a subsequence of length 3 from S (not necessarily contiguous) and convert it to uppercase letters to form T . Take a subsequence of length 2 from S (not necessarily contiguous), convert it to uppercase letters, and append X to the end to form T . Given strings S and T , determine if T is an airport code for S .

**Constraints:**
- S 3 10^5 string
- T 3 string
