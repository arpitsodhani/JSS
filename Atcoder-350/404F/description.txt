You are given a sequence of N positive integers A_1, A_2, ..., A_N.
Find the number of ways to choose a non-empty subsequence (not necessarily contiguous) such that the bitwise XOR of all chosen elements equals 0.

**Input:**
The input is given from Standard Input in the following format:
N
A_1 A_2 ... A_N

**Output:**
Print the answer modulo 998244353.

**Constraints:**
- 1 <= N <= 2 * 10^5
- 0 <= A_i < 2^{60}
- All input values are integers
