You are given an integer sequence of length N : A = (A_1,A_2,\ldots,A_N) . Determine whether there is a place in A where the same element appears three or more times in a row. More formally, determine whether there exists an integer i with 1 \le i \le N-2 such that A_i = A_{i+1} = A_{i+2} .

**Constraints:**
- 1 <= N <= 100
- 1 <= A_i <= 100
- All input values are integers
