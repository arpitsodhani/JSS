You are given three integers A, B, and C.
Determine whether you can make A equal to C by repeatedly adding or subtracting B.

**Input:**
The input is given from Standard Input in the following format:
A B C

**Output:**
Print `Yes` if you can make A equal to C, and `No` otherwise.

**Constraints:**
- -100 <= A, C <= 100
- 1 <= B <= 100
- All input values are integers
