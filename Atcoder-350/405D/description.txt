You are given N strings S_1, S_2, ..., S_N.
Find the number of pairs (i, j) (1 <= i < j <= N) such that S_i and S_j have at least one character in common.

**Input:**
The input is given from Standard Input in the following format:
N
S_1
S_2
...
S_N

**Output:**
Print the answer.

**Constraints:**
- 2 <= N <= 2 * 10^5
- 1 <= |S_i| <= 10
- S_i consists of lowercase English letters
