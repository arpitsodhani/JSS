There is a 3x3 grid. The cell at the i-th row and j-th column contains the integer A_{i,j}.
Takahashi and Aoki will play a game on this grid. They will alternately write their marks on empty cells, with Takahashi going first.
The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins.
If all cells are filled without anyone winning, the game is a draw.
Determine the outcome when both players play optimally.

**Input:**
The input is given from Standard Input in the following format:
A_{1,1} A_{1,2} A_{1,3}
A_{2,1} A_{2,2} A_{2,3}
A_{3,1} A_{3,2} A_{3,3}

**Output:**
Print `Takahashi` if Takahashi wins, `Aoki` if Aoki wins, and `Draw` if the game is a draw.

**Constraints:**
- 0 <= A_{i,j} <= 10^9
- All input values are integers
