You are given integers N and M . Print all integer sequences (A_1, A_2, \ldots, A_N) of length N that satisfy all of the following conditions, in lexicographical order. 1 \leq A_i A_{i - 1} + 10 \leq A_i for each integer i from 2 through N A_N \leq M What is lexicographical order? A sequence S = (S_1, S_2, \ldots, S_N) of length N is smaller in lexicographical order than a sequence T = (T_1, T_2, \ldots, T_N) of length N if and only if there exists an integer 1 \leq i \leq N such that both of the following hold: (S_1, S_2, \ldots, S_{i-1}) = (T_1, T_2, \ldots, T_{i-1}) S_i is less than T_i (as a number).

**Constraints:**
- 1 <= N <= 20
- 1 <= M <= 10
- All input values are integers
