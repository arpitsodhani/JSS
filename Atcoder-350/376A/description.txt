There is a mysterious button. When you press this button, you receive one candy, unless less than C seconds have elapsed since you last received a candy. Takahashi decided to press this button N times. He will press the button for the i -th time T_i seconds from now. How many candies will he receive?

**Constraints:**
- 2 <= N <= 100
- 1 <= C <= 100
- 1 <= T_i <= 100
- T_i < T_{i+1}
- All input values are integers
